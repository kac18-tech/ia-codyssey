# 🎬 영화 티어리스트 웹페이지 기획서 (Movie Tier Maker)

## 1. 프로젝트 개요
사용자가 영화를 검색하여 S, A, B, C, D 등급별로 분류하고, 자신만의 티어리스트를 만들어 URL 링크로 공유할 수 있는 웹 서비스입니다.

## 2. 주요 기능
### 🔍 영화 검색 (TMDB API)
- TMDB(The Movie Database) API를 활용한 실시간 영화 검색.
- 검색 결과로 영화 포스터 이미지와 제목 출력.

### 🖱️ 드래그 앤 드롭 (Drag & Drop)
- 검색된 영화 포스터를 상단의 티어 구역(S~D)으로 자유롭게 이동.
- 티어 간 이동 및 검색 결과창으로 되돌리기 기능.

### 🔗 URL 상태 저장 및 공유
- 별도의 서버(DB) 없이 현재 배치된 영화 데이터를 URL 파라미터에 인코딩하여 저장.
- 생성된 URL을 복사하여 타인에게 공유 시, 동일한 배치 화면 출력.

### 🚀 배포
- GitHub Pages를 이용한 정적 웹사이트 호스팅.

## 3. UI/UX 레이아웃 구성
### 상단: 티어 리스트 구역 (Tier Section)
- **S (Red):** 최상위 영화
- **A (Orange):** 추천 영화
- **B (Yellow):** 평범한 영화
- **C (Green):** 아쉬운 영화
- **D (Blue):** 비추천 영화
- 각 행은 영화 포스터가 들어갈 수 있는 가로형 드롭존(Drop-zone) 형태.

### 하단: 검색 및 결과 구역 (Search Section)
- **검색바:** 영화 제목 입력창 및 검색 버튼.
- **결과창:** 검색된 영화들이 나열되는 공간 (가로 스크롤 또는 그리드).

## 4. 기술적 상세 (Technical Specs)
- **언어:** HTML5, CSS3, JavaScript (ES6+).
- **API:** TMDB API (Search Movie Endpoint).
- **상태 관리:** 
  - 영화 배치 데이터(ID, Tier)를 JSON 형태로 관리.
  - `URLSearchParams`를 사용하여 브라우저 주소창 업데이트.
- **라이브러리 (선택):** SortableJS (부드러운 드래그 앤 드롭 구현 시).

## 5. 개발 로드맵
1. **1단계:** 기본 HTML/CSS 레이아웃 및 티어 디자인.
2. **2단계:** TMDB API 연동 및 검색 기능 구현.
3. **3단계:** 드래그 앤 드롭 로직 구현 (영화 이동).
4. **4단계:** URL 파라미터 생성 및 로드 로직 구현 (공유 기능).
5. **5단계:** GitHub Pages 배포 및 최종 테스트.
