- AI B (claude Haiku 4.5): 코디세이 플랫폼
- 동일한 기획서와 함께 전달한 요청: “첨부한 기획서로 html css javascript가 모두 들어있는 html 파일 하나를 만들어줘
외부 파일이나 서버 없이 브라우저에서 바로 열리게 하고, 화면문구는 한국어로 써줘. 완성된 html 파일로 제공해줘”

| 테스트 내용 | AI A | AI B |

| 음표 맞추기, 틀린 부분 시각적으로 확인하기 | 100%가 나옴 | 20%가 나옴 |

  A는 악보 그림이 깔끔했고, 제가 틀릴때 정답을 같이 알려줘서 틀린 부분을 잘 확인할 수 있었고, 정답을 맞추면 콤보표시로 재미도 주어서, 제가 의도한 기획방향대로 구현됐습니다.
