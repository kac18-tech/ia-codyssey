## 수정 기록

### 수정 기록 1
- **발견한 문제:** 페이지 로드와 동시에 문제가 시작되어 사용자가 준비할 시간이 부족함.
- **AI에게 전달한 요청:** "튜토리얼(시작 화면)이 있는 기획안에 맞게 HTML을 수정해줘."
- **수정 후 테스트 결과:** 인트로 화면이 먼저 나타나고 '연습 시작' 버튼을 눌러야 세션이 시작됨.
- **수정 이유:** 사용자의 심리적 대비와 학습 안내(온보딩)를 위해 화면 분리가 필요함.

### 수정 기록 2
- **발견한 문제:** 시작 버튼을 누르기 전에는 건반 위치와 소리를 미리 확인해볼 수 없음.
- **AI에게 전달한 요청:** "시작 전에도 키보드를 눌렀을 때 소리가 나고 건반이 눌리는 걸 연습한 다음 시작하게 해줘."
- **수정 후 테스트 결과:** 시작 전 '자유 연주 모드'에서 노란색 하이라이트와 함께 소리 확인 가능.
- **수정 이유:** 실제 테스트 전 건반 위치를 익히는 '탐색 단계'를 추가하여 학습 경험을 개선함.

## 사용자 테스트
- **테스트 참여자와 요청한 작업:** 피아노 독보 연습이 필요한 학생 / "안내문을 읽고 10문제를 풀어보세요."
- **사용자의 행동과 질문:** "시작 전에 눌러볼 수 있어서 좋네요.", "오답일 때 정답 위치가 표시되니 다음엔 안 틀릴 것 같아요."
- **받은 피드백:** 건반에 계이름(도, 레, 미)이 적혀 있어 초보자에게 매우 친절함.
- **반영 내용과 결과:** 건반 라벨에 한글 계이름과 키보드 알파벳을 병기하여 가독성 확보.
