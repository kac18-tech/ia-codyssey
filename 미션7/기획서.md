# 피아노 음표 연습 페이지 기획서 (최종본)

## 대상 사용자
- 피아노 완전 초보 (오른손 연습용)
- 데스크톱 환경에서 컴퓨터 키보드로 피아노 건반 위치와 음표를 익히고 싶은 학습자

## 사용 목적
- 높은음자리표(Treble Clef) 상의 음표를 보고 대응하는 피아노 건반을 컴퓨터 키보드로 누르는 반복 연습을 통해, 악보 독보력과 건반 위치 감각을 게임처럼 즐겁게 익히기 위함.

## 화면 구성과 동작

### 1. 시작 화면 (인터랙티브 튜토리얼)
- **구성:** 연습 방법 안내 문구, 키보드-피아노 건반 매핑 가이드, '연습 시작' 버튼.
- **자유 연주 모드:** 
    - 세션 시작 전, 사용자가 키보드(A, S, D, F, G, H, J)를 누르면 즉시 해당 음이 재생됨.
    - 누른 건반은 **노란색(Yellow)**으로 하이라이트되어 시각적 피드백 제공.
    - 사용자가 충분히 건반 위치를 익힌 후 '연습 시작' 버튼을 눌러 본 게임으로 진입.

### 2. 연습 화면 (메인 세션)
- **상단:** 악보 영역 — 현재 맞춰야 할 음표가 높은음자리표 위에 표시됨 (VexFlow 라이브러리 활용).
- **중앙:** 실시간 피드백 — 현재 연속 정답 카운트(Combo), 세션 진행 상태(예: 3/10).
- **하단:** 가상 건반 — 각 건반 위에 대응하는 컴퓨터 키 라벨 표시.

### 3. 결과 화면 (요약)
- **구성:** 10문제 완료 후 나타나는 팝업창.
- **내용:** 총 정답 수, 최고 연속 정답 기록, '다시 하기' 버튼.

### 4. 주요 동작 흐름
1. **진입 및 탐색:** 페이지 로드 시 자유 연주 모드 활성화 (노란색 하이라이트).
2. **세션 시작:** '연습 시작' 버튼 클릭 시 10문제 연습 세션 개시.
3. **판정 및 피드백:** 
    - 정답 시: 건반 **초록색** 하이라이트, 콤보 증가.
    - 오답 시: 누른 건반 **빨간색**, 정답 건반 **초록색** 표시, 콤보 리셋.
4. **진행:** 피드백이 800ms 동안 유지된 후 자동으로 다음 문제로 전환.
5. **종료:** 10문제 완료 시 결과 팝업 노출.

## 필요한 자료
- **악보 렌더링:** VexFlow 라이브러리 (CDN).
- **오디오 샘플:** C4(중앙 도)부터 B4까지의 합성음 또는 음원 파일.
- **기술 스택:** HTML5, CSS3, JavaScript (WebAudio API).

## 완료 기준
- **인터랙티브 튜토리얼:** 시작 버튼을 누르기 전에도 키보드 입력에 따른 소리와 시각 피드백(노란색)이 정상 작동해야 함.
- **진입 로직:** 시작 화면에서 '연습 시작'을 눌러야만 문제(악보)가 출제되어야 함.
- **반응 속도:** 키 입력 시 소리 재생과 시각 피드백 사이의 지연 시간이 체감되지 않아야 함 (300ms 이내).
- **세션 관리:** 한 세션은 정확히 10문제로 구성되며, 종료 후 결과 요약이 표시되어야 함.

## 추가 기능 (추후 구현)
- **힌트 시스템:** 오답 시 정답 건반 위치를 깜빡여주는 기능.
- **난이도 조절:** 연습할 음역대 선택(낮은음자리표 추가 등).
- **음표명 표시:** 건반이나 악보 아래에 '도, 레, 미' 이름을 보여주는 토글 기능.

## 한계 및 비목표
1. **단음 연습 전용:** 화음(여러 음 동시 입력)은 구현 범위에서 제외함.
2. **데이터 저장 불가:** 로컬 스토리지나 서버를 이용한 누적 성적 저장 기능은 포함하지 않음.
3. **데스크톱 최적화:** 물리 키보드 입력을 전제로 함.

## 검증 방법
- **수동 테스트:** 
    - 시작 전 자유 연주 시 노란색 하이라이트와 소리가 일치하는지 확인.
    - 10문제 풀이 과정에서 정/오답 색상 피드백이 기획대로 작동하는지 확인.
    - 결과 팝업의 수치(정답 수, 콤보)가 정확한지 확인.
