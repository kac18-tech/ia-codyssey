🎬 프로젝트 기획서: Movie Tier Maker (가칭)
1. 개요
서비스 명: Movie Tier Maker
목적: 사용자가 좋아하는 영화를 검색하여 S-A-B-C-D 등급별로 분류하고, 이를 저장하거나 타인과 공유할 수 있는 웹 서비스
핵심 가치: 직관적인 드래그 앤 드롭 UI, 세련된 시네마틱 디자인, 간편한 URL 공유
2. 주요 기능 (MVP - 최소 기능 제품)
2.1 영화 검색 및 데이터 연동
TMDB API를 활용한 실시간 영화 검색
검색 결과에서 포스터와 제목을 카드 형태로 노출
2.2 티어리스트 조작 (핵심 경험)
고정 티어: S, A, B, C, D (5단계)
드래그 앤 드롭: 검색 결과에서 티어 영역으로, 또는 티어 간 영화 카드 이동 (dnd-kit 라이브러리 활용)
반응형 레이아웃: 모바일과 데스크톱 모두에서 최적화된 조작감
2.3 저장 및 공유
저장하기: 현재 구성한 티어표를 Supabase DB에 저장
공유하기: 고유 ID가 포함된 URL(예: /share/[id]) 생성
읽기 전용 페이지: 공유된 URL 접속 시 수정은 불가능하고 조회만 가능한 페이지 노출
3. 디자인 컨셉
배경(Background): 영화관(Theater) 느낌의 고화질 이미지 사용, 너무 어둡지 않게 밝기 조절(Overlay 0.5)
티어 레이블(Tier Labels):
유리 질감(Glassmorphism): 강한 블러(backdrop-filter)와 반투명 테두리 적용
컬러 포인트: 배경색은 투명하게 유지하되, 티어 글자(S~D)에만 고유 컬러와 네온 글로우 효과 적용
전체 무드: 현대적이고 세련된 다크 모드 기반의 시네마틱 UI
4. 기술 스택
Frontend: Next.js (App Router), Tailwind CSS
State & Drag: dnd-kit (드래그 앤 드롭 라이브러리)
Backend/DB: Supabase (PostgreSQL, 인증 및 데이터 저장)
API: TMDB API (영화 정보)
Deployment: Vercel
5. 데이터 구조 (Supabase)
5.1 tier_lists 테이블
컬럼명	타입	설명
id	UUID (PK)	티어표 고유 식별자 (공유 URL에 사용)
title	Text	티어표 제목 (선택 사항)
data	JSONB	티어별 영화 ID 및 포스터 경로 데이터
created_at	Timestamp	생성 일자
