# 피아노 음표 연습 페이지

## 대상 사용자

- 피아노 완전 초보(오른손 연습용, 데스크톱 환경에서 키보드로 연습하고 싶은 사람)

## 사용 목적

- 트레블 클레프(오른손) 상의 단일 음표를 보고 대응하는 피아노 건반(중앙부)을 컴퓨터 키보드로 눌러 건반 위치와 음을 익히기 위한 반복 연습(게임형).

## 화면 구성과 동작

- 상단: 악보 영역(트레블 클레프만) — 현재 출제된 음표가 악보에 표시됨.
- 중앙: 실시간 피드백 영역 — 현재 음표명(C4 등), 연속 정답 카운터(눈에 띄게 표시), 세션 정보(X/10).
- 하단: 가상 건반(시각화된 흰/검은 건반) — 각 건반 위에 대응 컴퓨터 키 라벨 표시.
- 우측 상단: 시작/재시작 버튼, 세션 진행 상태(몇 문제 남음), 최종 요약 팝업(세션 종료 시).
- 동작 흐름:
  - 사용자가 시작 버튼 클릭 → 무작위로 선택된 10음표 세션 시작.
  - 각 음표가 악보에 표시됨.
  - 사용자가 해당하는 컴퓨터 키를 누르면 즉시 해당 피아노 샘플 재생.
    - 정답: 표시된 악보 음표와 해당 가상 건반이 초록으로 하이라이트, 연속 정답 카운터 +1.
    - 오답: 표시된 악보 음표과 누른 가상 건반이 빨강으로 하이라이트, 연속 정답 카운터 0으로 리셋.
  - 하이라이트는 짧은 애니메이션(페이드/확대)으로 표시되며 800ms 후 자동으로 다음 음표로 진행.
  - 10음표 모두 완료되면 간단한 요약(총 정답 수, 최고 연속 정답)을 표시하고 재시작 가능.

## 필요한 자료

- 악보 렌더링 라이브러리(권장: VexFlow 등) 또는 간단한 SVG/Canvas 악보 구현.
- 피아노 실제 샘플(중앙부 C4–B4 범위의 샘플들, SoundFont 또는 WAV 샘플 집합).
- WebAudio API 기반 재생 로직(샘플 로드/캐싱, 재생).
- 프론트엔드 리소스: HTML/CSS/JS, 가상 건반용 SVG 또는 CSS 그래픽, 간단한 애니메이션 CSS.
- (선택) 샘플 로딩 상태 표시용 로더 UI.

## 완료 기준

- 기능적 조건:
  - 악보·가상 건반·키 매핑 라벨이 화면에 모두 보인다.
  - 사용자가 키를 누르면 즉시(체감 지연 < 약 200–300ms, 샘플 미로딩 시 제외) 소리 재생과 시각적 피드백(정답=초록, 오답=빨강)이 발생한다.
  - 한 세션은 정확히 10음표로 구성되어 자동으로 진행되고(하이라이트 후 800ms), 10음표 완료 후 요약이 표시된다.
  - 연속 정답 카운터가 정확히 동작(정답 시 증가, 오답 시 0으로 리셋)한다.
- 동작·제약:
  - 로컬/서버에 성적·진도 데이터를 저장하지 않는다(저장 기능 없음).
  - 로그인 불필요(익명 사용, 단일 페이지).
  - 데스크톱 브라우저(물리 키보드)에서 정상 작동해야 한다.

## 추가 기능

- 연속 정답 카운터 (요구사항에 포함, 화면 중앙에 강조 표시).
- (추후 구현 제안) 힌트(틀리면 정답키 깜빡임), 텍스트 음표명 토글, 레벨 확장(범위 확대), 색약 모드.

## 한계 및 비목표

1. 왼손용 베이스 클레프(바이올린/베이스 병행)나 양손 연습은 이번 구현 범위에서 제외한다 — 트레블 클레프(오른손)만 지원.
2. 페달(서스테인) 및 페달 효과는 포함하지 않는다.
3. 저장(로컬Storage 또는 서버 저장) 및 사용자 계정 기능은 제공하지 않는다.
4. 모바일 대응(터치 입력 최적화)은 우선순위에서 제외 — 데스크톱 중심 설계.
5. 색약 모드/접근성 별도 모드는 이번 단계에 포함하지 않음(추후 추가 가능).
6. 샘플 로딩은 네트워크를 통한 로드가 기본이며, 완전 오프라인 작동은 보장하지 않음(샘플을 번들로 포함하면 일부 오프라인 가능).

## 검증 방법

- 수동 테스트(사용자 관점)
  - 실제 초보 사용자 또는 개발자가 5~10회 세션을 플레이하여 다음을 확인:
    - 악보와 가상 건반이 시각적으로 올바르게 매칭되는지.
    - 키 입력 시 소리 재생과 색상 피드백(초록/빨강)이 즉시 발생하는지.
    - 연속 정답 카운터가 정답/오답에 따라 올바르게 증가/리셋되는지.
    - 세션이 정확히 10문제로 구성되어 종료 후 요약이 뜨는지.
- 기능 테스트(개발자 관점)
  - 키보드 이벤트 시나리오(정답 입력, 오답 입력, 빠른 연속 입력)를 자동화된 스크립트 또는 수동 체크리스트로 재현하여 상태 변화(하이라이트, 카운터, 다음 문제 진행) 검증.
  - 오디오 재생 성능: 키 입력 시 음성 출력까지의 지연(주관적)이 200–300ms 이내인지 체크(개발자 툴로 타임스탬프 확인 가능).
  - 샘플 미로딩 상황 테스트: 샘플 로딩 전/중/후 동작(로더 표시, 폴백 합성음 여부) 확인.
- 브라우저 호환성
  - 최신 데스크톱 브라우저(Chrome, Edge, Firefox, Safari)에서 기본 기능(키입력, WebAudio, Canvas/SVG 렌더링) 동작 확인.
